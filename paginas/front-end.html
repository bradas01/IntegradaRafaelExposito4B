Formação Técnica / Front-End

Front-End

As três linguagens que usei para construir este portfólio.

HTML

Organiza a estrutura e o significado do conteúdo. Usei tags semânticas como header, nav, main, section, article, figure e footer.

<figure>
  <img src="..." alt="...">
  <figcaption>Crédito</figcaption>
</figure>

CSS

Controla cores, fontes e layout. As cores ficam em variáveis no :root, e as grades de cards usam CSS Grid, que se adapta sozinho ao tamanho da tela.

.grade-cards {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(220px, 1fr));
}

JavaScript

Adiciona interatividade: abre e fecha o menu no celular e move os carrosséis quando clico nas setas.

botaoMenu.addEventListener("click", function () {
  menu.classList.toggle("aberto");
});

Meu projeto: este portfólio

O site tem 29 páginas ligadas por um menu único. A organização das pastas separa as páginas (paginas/), o estilo (css/), o JavaScript (js/) e as imagens (imagens/, dividida em subpastas por assunto). Todos os nomes de arquivo estão em minúsculas, sem espaços e sem acentos.

O visual usa tons de azul, cards e cantos arredondados. No celular, o menu vira um botão e as colunas passam a ficar uma embaixo da outra.
