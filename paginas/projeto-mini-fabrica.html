Formação Técnica / Projeto de IoT

Mini Fábrica Inteligente

Projeto do 3º ano com ESP32, ESP32-CAM e banco de dados.

O desafio

Simular, em escala reduzida, uma linha de produção automatizada, como as das indústrias, em que as máquinas identificam o que está sendo produzido e registram essas informações sozinhas.

Objetivo

Usar o ESP32 para controlar a mini fábrica, a câmera ESP32-CAM para capturar imagens dos objetos e um banco de dados para guardar os registros da produção.

ESP32ESP32-CAMBanco de dadosTrabalho em equipe

Materiais e tecnologias

  • ESP32: microcontrolador com Wi-Fi e Bluetooth, o "cérebro" do projeto
  • ESP32-CAM: placa ESP32 com câmera, usada para capturar imagens
  • Banco de dados: guarda as informações coletadas pelos dispositivos

1. Planejamento

Definir o que a mini fábrica deveria fazer, escolher os componentes e dividir as tarefas no grupo.

2. Construção

Montar a estrutura e os circuitos, programar o ESP32 e a ESP32-CAM e preparar o banco de dados.

3. Integração

Fazer os dispositivos se comunicarem pela rede e enviarem os dados para o banco.

4. Testes

Verificar a captura das imagens e o registro das informações, corrigindo os erros encontrados.

O que aprendi

O projeto juntou quase tudo o que estudei no curso: programação de microcontroladores, comunicação entre dispositivos (a base da Internet das Coisas) e banco de dados. Também mostrou, em pequena escala, como a automação e o registro de dados funcionam nas fábricas de verdade.

Como funciona

O funcionamento segue o caminho dos dados em um sistema de IoT:

  1. O objeto chega à área de leitura da mini fábrica.
  2. A ESP32-CAM captura a imagem do objeto.
  3. O ESP32 processa a informação e controla as partes da mini fábrica.
  4. Os dados (qual objeto passou e quando) são enviados pela rede Wi-Fi para o banco de dados.
  5. Com os registros guardados, é possível saber quantos objetos de cada tipo foram produzidos.

Desafios

Projetos que juntam câmera, microcontrolador e banco de dados têm desafios em cada parte: a iluminação influencia a qualidade da imagem, a conexão Wi-Fi precisa ser estável para enviar os dados, e o banco de dados precisa estar bem modelado para guardar as informações sem repetição. Por isso, o caminho mais seguro é testar cada parte separadamente antes de juntar tudo.
